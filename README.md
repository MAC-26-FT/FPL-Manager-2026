# FPL Manager — final architecture

1. Use `FPL_2026_27_FPL_Manager_Final.xlsx` for the full model, historical review and manual team-news inputs.
2. Use the PWA (`index.html`) as the iPhone/iPad/Mac dashboard.
3. Both use the same projection concepts: expected minutes, xG, xA, form, fixtures, 6/8-GW xP, value, minutes risk and captain ceiling.
4. Refresh official FPL data before weekly decisions.
5. Keep projected minutes/start probability and late team news as human overrides.

Official FPL is the primary data source. No FPL password is needed by the PWA.
